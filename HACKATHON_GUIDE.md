# Hackathon guide: actions and submission

The full Tectonic Hackathon participants guide is kept outside this code repository in the project workspace. These are the key project requirements from it.

## Required submission

Submit through Builderbase, with:

- A short project description.
- A demo video under 3 minutes. The team also wants this video published on YouTube, with its link included in this repository.
- A link to this GitHub repository.
- Before-and-after screenshots from the Aikido platform.

Only one project is submitted per team.

## Aikido security audit

The Aikido AI Code Audit is required and is worth 10% of the assessment. Connect the hackathon GitHub repository, run the audit, address and mark findings as resolved, and capture screenshots of the platform before and after.

## Rules to follow

- Build within the official hackathon time slot.
- Keep the GitHub repository public and accessible until judging is complete.
- Do not change the code or submission after the final submission.
- Include a README that explains the project, how to run it, and anything unfinished.
- Check that the judges can open all submitted links.
- Do not upload passwords, API keys, or confidential data.

Judges score creativity, technical ability, fit to the challenge, and security.
