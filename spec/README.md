## Technical constraints

- The prototype needs a web server.
- Most content is static, with a small amount of controller logic.
- Node.js is the preferred runtime.
- Prefer plain JavaScript, organized into clear modules; avoid adding a front-end framework or TypeScript without a concrete need.
- Provisional layout: `public/` for static HTML, CSS, browser JavaScript, and assets; `src/` for the server, routes, and controller logic.
- Choose the server library after the primary user flow is clear.
